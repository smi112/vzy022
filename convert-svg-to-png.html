🎨 Konwerter SVG → PNG dla iOS

Problem: iOS nie obsługuje SVG dla apple-touch-icon. Musimy przekonwertować SVG na PNG.

Rozwiązanie: Ten skrypt automatycznie skonwertuje 3 pliki SVG na PNG.
Krok 1: Kliknij przycisk poniżej aby wczytać pliki SVG z folderu /images
✅ Konwersja zakończona! Teraz kliknij każdy przycisk "Pobierz PNG" aby pobrać pliki.
Krok 2: Po pobraniu wszystkich 3 plików PNG, skopiuj je do głównego folderu projektu:
  • apple-touch-icon.png → główny folder
  • icon-192.png → główny folder
  • icon-512.png → główny folder
